# 2026-11-16：DSCache / MemInStream 字节预算适配

基础提交：`a544c7db80e4da2920b1e83e8f3ecbdf470e91f7`。
本轮目标为代码与数据准备验收，不启动真实7B GPU实验，不影响正在运行的InfiniPot-V。

- 在专用 `biocache-baseline-DSCache` 环境中将 Transformers 4.49.0 升至4.57.3，
  tokenizers 0.21.4升至0.22.2；保留Torch 2.9.0+cu128及PyAV16.0.1。
- 主预算1.75GiB，另支持0.875/1.3125GiB。默认近期4帧对，历史容量按视频token数、
  dtype、前缀副本、近期特征与位置、一个源尺寸待配对帧、元数据预留动态计算。
  实际稳定持久状态与额外静态状态按总字节检查，超限报错。
- 历史FIFO淘汰；不附加CPU/磁盘隐形归档。每题克隆历史并按需重建近期KV。
  记录历史容量、已保留帧对、淘汰数量和最早/最新保留时间。
- 独立MemInStream驱动、提示、评分与监控全部位于biocache_adapt，单独checkout即可运行。
  单选只返回一个字母；多选返回选项集合，不将标签值或正确选项数量传入模型。
- 统一1fps真实PTS、153664最大像素、greedy、256新token、两核CPU。
  拒绝未来帧/对话，最后一题之后继续解码到EOF；近期特征按需构建KV是DSCache机制，
  不将“完整输入”等同于“全部历史原始KV同时保留”。
- 同步计量对象ID复用/引用环修复，视频结束后GC/同步/empty_cache，记录当前和峰值显存。
- 断点恢复校验annotation/video metadata/config/protocol指纹，跳过完整视频、
  对部分视频重建历史但不重复回答。运行目录锁防止双worker；错误指纹和误重跑不覆盖原结果。
- 14项测试通过：真实微型Qwen CPU、recent-prefill数值等价、预算/淘汰/计量，
  单/多选与标签隔离，真实合成视频EOF/因果查询/评分/恢复/目录锁/覆盖保护。
  真实数据仅prepare：3377视频、3795题；3759单选、36多选，排除2个超长视频。

使用说明、预算公式和启动命令见 `biocache_adapt/MEMINSTREAM.md`。
验证环境、测试日志和Python源码SHA256见 `biocache_adapt/qwen_validation.json`。

本版使用来源位置MRoPE，并非原版position-agnostic编码或ls_N采样的严格复现。
真实7B GPU显存/性能、官方方法对照与全量准确率仍待执行。
